# Ainesh Joel Hamilton (@Bloxi17) — Developer Portfolio

A next-generation, high-performance personal portfolio and introduction platform custom-crafted for **Ainesh Joel Hamilton (`@Bloxi17`)**.

Designed and built to replace generic "vibe-coded" AI templates with an authentic **Obsidian Minimalist-Editorial** aesthetic, **Three.js real-time 3D WebGL motion**, **Apple-grade fluid spring mechanics**, and a **two-tier magnetic cursor**.

---

## 💎 Design System & Engineering Highlights

- **Anti-"Vibe-Coded" Architecture**:
  - Replaced random AI purple/gold ambient glow blobs with disciplined obsidian charcoal surfaces and hairline borders (`1px solid rgba(255,255,255,0.08)`).
  - Banished generic pulsating badges and emoji titles with real-time UTC/IST telemetry and standardized `1.5` stroke Phosphor/Radix SVG primitives.
  - Replaced cookie-cutter 4-column cards with an asymmetrical **Bento Grid** highlighting backend databases, WebGL mathematics, and performance budgeting.
- **Interactive Three.js 3D Background**:
  - Procedural crystalline icosahedron with metal core and illuminated wireframe.
  - Linked directly to page scroll progress across sections (Hero $\rightarrow$ Projects $\rightarrow$ Capabilities $\rightarrow$ Contact).
  - Apple direct manipulation: visitors can click, drag, and toss the 3D core with realistic momentum physics (`decelerationRate: 0.998`).
  - Throttled automatically when the browser tab is hidden to ensure zero battery drain.
- **Two-Tier Fluid Magnetic Cursor**:
  - Point dot with zero latency.
  - Damped spring follower ring (`damping: 1.0`, `response: 0.25s`).
  - Contextual morphing into `(ORBIT)`, `(EXPLORE)`, and magnetic snap on buttons.
  - Automatic touch gating: hidden completely on touchscreens (`@media (pointer: coarse)`).
- **Interactive 3D Engine Playground**:
  - Real-time on-page controls for recruiters and engineers to customize orbit velocity, wireframe toggles, and edge lighting color.
- **Tactile Command Palette (`Cmd + K` / `Ctrl + K`)**:
  - Quick keyboard search for jumping across sections, copying verified email, or toggling low-power 3D mode.
- **Flagship Project Deep Dive**:
  - In-depth architectural case study for **First Step Senior Secondary School**, including custom HTML5 Canvas 3D ribbons, Node.js + `better-sqlite3` CMS, and mobile touch drawer engineering.

## 🚀 Local Development & Preview

Because this codebase is built with modern standard web technologies and native ES modules, you can run it immediately with any static server:

```bash
# Using Python built-in server:
python -m http.server 3000

# OR using Node npx:
npx serve .
```

Open `http://localhost:3000` in your browser.

## 🌐 Deploying to GitHub Pages (`bloxi17.github.io`)

This project is structured for **zero-friction GitHub Pages deployment**:
1. Commit and push the files directly to your `bloxi17/bloxi17.github.io` repository on the `main` branch:
   ```bash
   git init
   git add .
   git commit -m "feat: complete obsidian minimalist portfolio overhaul"
   git remote add origin https://github.com/Bloxi17/bloxi17.github.io.git
   git push -u origin main
   ```
2. In your repository on GitHub, navigate to **Settings** $\rightarrow$ **Pages**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Your site will automatically go live at **`https://bloxi17.github.io`**!
